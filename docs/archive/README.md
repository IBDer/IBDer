# Archive

Superseded documents, kept for provenance only.

**Nothing here is authoritative.** Rules that used to live in these files now live in one of five
places: [AGENTS.md](../../AGENTS.md) (how to work), [CONTEXT.md](../../CONTEXT.md) (vocabulary),
[docs/adr/](../adr/) (decisions), [openspec/](../../openspec/) (what the system does), and
[review-gates.md](../process/review-gates.md) (the loop). Style rules that could be executed moved
into .swiftlint.yml and .swiftformat instead of prose.

If you need to know why something is the way it is, read docs/adr/. If you need to know what a rule
used to say, read here — then check whether an ADR superseded it.
