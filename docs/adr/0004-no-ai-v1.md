# ADR-0004: The first version contains no AI

- **Status**: Accepted
- **Date**: 2026-10-11

## Decision

Recording, aggregation, and briefing in the first version are entirely deterministic pipelines, and no model is called.

## Rejected options

- **Cloud LLM for conversational recording and generative briefings**: it directly conflicts with the organization's rule of "do not submit identifiable patient information to third-party AI services", and it would introduce entrusted-processing and cross-border-transfer issues.
- **On-device natural language parsing**: the direction is right, but it is a differentiation problem, not a first-version feasibility problem.

## Consequences

- Natural language recording is evaluated as a separate change after first-version validation; if it is done, on-device processing is preferred, with data never leaving the device.
- The "briefing" is a templated aggregation in the first version, not a generative summary.
