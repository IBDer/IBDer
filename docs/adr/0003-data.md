# ADR-0003：纯本地存储 + 手动加密备份

- **状态**：已接受
- **日期**：2026-10-11

## 决定

- 数据只存设备本地。
- 提供**成对**的加密导出 / 导入能力（含版本与完整性校验，恢复前先验证）。
- 提供给医生的导出文件；分享行为必须由用户明确触发。

## 被否决的选项

- **iCloud / CloudKit 私有同步**：在中国大陆需要额外说明与账号体系，首版不必要。
- **自建账号 + 云同步**：直接触发受托处理、数据出境、备案等一整套义务。

## 后果

- 必须如实告知用户：单设备会因卸载、损坏、换机而丢失数据，以及备份能覆盖到什么程度。
- 备份与恢复必须成对实现；只做导出不做导入视为未完成。
