# ADR-0003: Purely local storage + manual encrypted backup

- **Status**: Accepted
- **Date**: 2026-10-11

## Decision

- Data is stored only on the device, locally.
- Provide **paired** encrypted export / import (with version and integrity checks; verify before restoring).
- Provide an export file for doctors; sharing must be explicitly triggered by the user.

## Rejected options

- **iCloud / CloudKit private sync**: in mainland China it requires additional disclosures and an account system, and is unnecessary for the first version.
- **Self-hosted accounts + cloud sync**: it directly triggers a whole set of obligations — entrusted processing, cross-border data transfer, regulatory filing.

## Consequences

- Users must be told truthfully: that a single device will lose data through uninstalling, damage, or switching phones, and to what extent backup can cover that.
- Backup and restore must be implemented as a pair; export without import counts as incomplete.
